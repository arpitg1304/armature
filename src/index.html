Studio Setup

Task setup

One long peg + a fixed cube with a square through-hole. Pick, align, insert and release. Success requires a seated, upright, stable peg. Generous clearance; no force control. Scripted demo tuned for Panda and xArm 6; SO-101 and UR5e are experimental.

Robot & environment
Robot specifications

Blender-built cell. Supply bins and fixtures are visual; manipulation uses the flat bench surface.

Robot tools

Robot physics

Dynamic mode selects Panda. Menagerie link inertias and mesh collisions; 480 Hz by default. Cannon constraint experiment, not MuJoCo-equivalent. No self-collision or hardware calibration. Existing motion plans may fail. Reset after changing these settings.

RL experiment · reach

CEM searches three feedback gains through real environment steps. Evaluates three held-out goal seeds. Panda only. Runs locally; no neural model or server.
